<2025-07-29 Tue>
+ 调整了一下 littlefoot 的样式，使它看起来像是一个 footnote。
+ 移除 giscus 评论。

<2025-07-17 Thu>
+ 手机上的字体再增大了一点，最小字号是 22px。
+ 增加了「返回顶部」的功能。见 [[https://github.com/Spike-Leung/taxodium/blob/org-publish/publish/js/backtop.js][backtop.js]]。

<2025-07-16 Wed>

+ 解决 giscus 的主题异常问题，通过动态加载 giscus，确保在 light / dark mode 下都能渲染正确的主题。
+ 顺手更新了 [[file:setup-blog-color-scheme.org][给博客添加 dark mode]]。

<2025-07-14 Mon>

+ 让 sidenote 分布在文章的两边，充分利用两边的空间，而不是都放在一边，显得不均匀。
+ 增大 pagefind 的 [[https://pagefind.app/docs/ui/#excerpt-length][Excerpt length]]，便于看到关键字附近更多的内容，更好的找到想要找的内容。
+ 调整 pagefind 的 border 颜色，使其更明显一些。
+ 调整 search 和 rss 页面的字体，保持统一。

<2025-07-12 Sat>

+ 文章中尝试用是 =<hr>= 去分割段落，同时给 =<hr>= 添加了一些样式。

<2025-07-09 Wed>

+ 重新添加 [[https://chinese-font.netlify.app/zh-cn/fonts/lxgwwenkai/LXGWWenKai-Regular][霞鹜文楷]] 字体，粗体现在似乎看起来对比度还可以；字体放到网站的静态资源中托管；一定程度上提高文字的耐看度。

<2025-07-08 Tue>

+ 添加背景图，内容过多的时候，纯色背景有些单调，使得页面看起来有些枯燥，设置背景使得页面相对耐看一些。
  + 现在是一张叶子的背景图，倒是挺像落羽杉的
+ figcaption 只有一行的时候居中，好看一些，但对于一些小图片不太合适，需要手动修改样式，有点麻烦。
+ 页脚添加了 support me，support me 页面添加了支付宝收款码。
+ 调整 list 的样式，避免部分 list item 出现额外的 margin-block。

<2025-07-01 Tue>

+ 在宽度大于 768px 的设备上，点击图片，在新 tab 展示，可以进一步放大查看。见 [[https://github.com/Spike-Leung/taxodium/blob/org-publish/publish/js/image-enhanced.js][image-enhanced.js]]。

<2025-05-07 Wed>

<2025-04-28 Mon>

+ 将 giscus 切换成中文。

<2025-04-26 Sat>

+ 集成 [[https://github.com/goblindegook/littlefoot][littlefoot]]，最开始是在 [[https://www.geedea.pro/][極客死亡計劃]] 看到的，感觉交互不错，现在我也集成了，当屏幕比较小的时候会用 littlefoot，屏幕大的时候会现实 sitenote。
+ 稍微扩大导航的点击范围。
+ 调整 TODO 关键字的颜色，原来的红色比较刺眼，换成一个相对柔和的红色。
+ 修复暗黑模式下，pre 元素的背景色异常。

<2025-04-17 Thu>

+ 使得 Atom feed 符合规范，see: [[file:valid-your-feed.html][验证你的 RSS/Atom feed 是否有效]]。

+ 调整文字的颜色，符合 APCA 定义的 Lc90。[fn:2]

<2025-04-14 Mon>

+ 代码块添加了复制按钮，便于复制代码。[fn:3]

+ 移除 [[https://chinese-font.netlify.app/zh-cn/fonts/lxgwwenkai/LXGWWenKai-Regular][霞鹜文楷]] 字体，使用默认中文字体，因为霞鹜文楷的粗体太不明显了。[fn:4]
+ preload [[https://www.brailleinstitute.org/freefont/][Atkinson Hyperlegible]] 字体，并设置字体缓存。
