- [[https://stuffandnonsense.co.uk/blog/swapping-a-lightweight-image-for-an-animated-svg/][Swapping a lightweight image for an animated SVG]] by Andy Clark

  作者網站有一些 SVG 動畫，原來不管用户是否能看到都會加載，
  會影响頁面加載性能和降低用户體驗，
  於是他优化了一下，基於媒體查詢决定資源如何加載。

- [[https://csswizardry.com/2026/07/meaasuring-component-performance-with-the-container-timing-api/][Measuring Component Performance with the Container Timing API]] by Harry Roberts

  文章介紹了如何 [[https://github.com/WICG/container-timing][Container Timing API]]，以及如何用它來監測頁面中某個組件的性能。
  目前只有 Chrome 支持這個 API。

- [[https://master.dev/blog/when-you-need-to-make-a-triangle-think-conic-gradients/][When You Need To Make a Triangle, Think Conic Gradients]] by Chris Coyier

  利用 [[https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/gradient/conic-gradient][Conic Gradients]] 繪製三角型。

- [[https://nerdy.dev/css-infinity-use-cases][CSS Infinity Use Cases]] by Adam Argyle

  文章分享了一些 [[https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/calc-keyword#infinity][CSS Infinity]] 的用例，當需要一個極大值時會很方便。
