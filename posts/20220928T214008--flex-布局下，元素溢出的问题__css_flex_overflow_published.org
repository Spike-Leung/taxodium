* 问题
:PROPERTIES:
:CUSTOM_ID: 1e74c31a-4677-4cac-99aa-06e50ab292af
:END:
有一个 flex box，宽度是 400px，里面有一个 item，item 中有一段很长的文字，文字不换行。

由于外层盒子设置了宽度，预期是父盒子宽度能限制住 item，避免溢出。

* 原因
:PROPERTIES:
:CUSTOM_ID: bd478911-a841-40f1-9008-e3a5fcb0924e
:END:

** TL;DR
:PROPERTIES:
:CUSTOM_ID: 506cfe7f-f1ba-4c39-96d1-ac3e8bb053a8
:END:

会溢出是因为在这个例子中，flex item 的 /最小尺寸(minimum size)/ 是文本的长度，flex item 只能缩小到文本长度，而文本越长，flex item 就越长，也就溢出了。

通过设置 =overflow= 属性，可以让最小尺寸变为 0，从而让 flex item 可以缩小到容器内而不溢出；

设置 =min-width: 0= 同理，可以让 flex item 可以缩小到很小，避免溢出；

设置 =width: 0= 则也会影响最小尺寸，同时也设置了 flex item 的宽度，但因为宽度为 0，还需要设置 =flex-grow: 1= ，让 flex item 延伸容器剩余空间。

** 详细分析
:PROPERTIES:
:CUSTOM_ID: 413f277a-515a-420a-8cbc-a45329b88de3
:END:
当 flex item 没有设置 flex 属性时，默认值是 =flex: initial= ，相当于 =flex: 0 1 auto=,

也即 =flex-grow: 0; flex-shrink: 1: flex-basic: auto;=

这个[[https://www.w3.org/TR/2018/CR-css-flexbox-1-20181119/#flex-initial][默认值]]的效果是：

- flex-grow: 0 :: item 无法延伸尺寸
- flex-shrink: 1 :: item 可以缩小, 但最多只能缩小到 item 的最小尺寸
- flex-basic: auto :: 根据 item 的 width/height 来设置尺寸，如果 width/height 没有指定，则会根据内容去计算尺寸。

最小尺寸的计算，在 [[https://www.w3.org/TR/2018/CR-css-flexbox-1-20181119/#min-size-auto][4.5. Automatic Minimum Size of Flex Items]] 中有描述：

#+begin_quote
To provide a more reasonable default minimum size for flex items,

the used value of a main axis automatic minimum size on a flex item that is /not a scroll container/ is a /content-based minimum size/;

for scroll containers the automatic minimum size is /zero/, as usual.

[[https://www.w3.org/TR/2018/CR-css-flexbox-1-20181119/#min-size-auto:~:text=To%20provide%20a%20more%20reasonable%20default%20minimum%20size%20for%20flex%20items%2C%20the%20used%20value%20of%20a%20main%20axis%20automatic%20minimum%20size%20on%20a%20flex%20item%20that%20is%20not%20a%20scroll%20container%20is%20a%20content%2Dbased%20minimum%20size%3B%20for%20scroll%20containers%20the%20automatic%20minimum%20size%20is%20zero%2C%20as%20usual][Source]]
#+end_quote

也就是说，如果 flex item 是一个滚动容器（[[https://www.w3.org/TR/css-overflow-3/#scroll-container][scroll container]]，即设置了 overflow 属性），那么最小尺寸就是 0。

所以，当设置了 =overflow= 后，flex item 可以尽可能地缩小直到刚好填满 flex container。

借助 firefox，可以看此时的尺寸如下：

#+attr_html: :class dark-adjust
#+CAPTION: 由于设置了 overflow: auto; 使得 flex item 最小尺寸是 0，flex-shrink 可以收缩到容器内，避免溢出。
[[file:./images/flex-box-with-overflow/layout-overflow.webp]]

如果 /不是/ 可滚动元素，有以下描述：

#+begin_quote
In general, the content-based minimum size of a flex item is the
smaller of its /content size suggestion/ and its /specified size
suggestion/.

However, if the box /has an aspect ratio and no specified size/, its
content-based minimum size is the smaller of its /content size
suggestion/ and its /transferred size suggestion/.

If the box /has neither a specified size suggestion nor an aspect
ratio/, its /content-based minimum size/ is the content size suggestion.

[[https://www.w3.org/TR/2018/CR-css-flexbox-1-20181119/#min-size-auto:~:text=To%20provide%20a%20more%20reasonable%20default%20minimum%20size%20for%20flex%20items%2C%20the%20used%20value%20of%20a%20main%20axis%20automatic%20minimum%20size%20on%20a%20flex%20item%20that%20is%20not%20a%20scroll%20container%20is%20a%20content%2Dbased%20minimum%20size%3B%20for%20scroll%20containers%20the%20automatic%20minimum%20size%20is%20zero%2C%20as%20usual][Source]]
#+end_quote

/specified size suggestion/ 的定义：

#+begin_quote
If the item’s computed [[https://www.w3.org/TR/2018/CR-css-flexbox-1-20181119/#main-size-property][main size property]] is definite, then the
specified size suggestion is that size (clamped by its max main size
property if it’s definite). It is otherwise undefined.

[[https://www.w3.org/TR/2018/CR-css-flexbox-1-20181119/#min-size-auto:~:text=If%20the%20item%E2%80%99s%20computed%20main%20size%20property%20is%20definite%2C%20then%20the%20specified%20size%20suggestion%20is%20that%20size%20(clamped%20by%20its%20max%20main%20size%20property%20if%20it%E2%80%99s%20definite).%20It%20is%20otherwise%20undefined][Source]]
#+end_quote

也就是说，只要给 flex item 设置 ~width~ 或者 ~min-width~ ，那么从这些值上去计算最小尺寸。

所以可以通过设置 =min-width: 0= ，让 flex item 可以尽可能的缩小。

#+attr_html: :class dark-adjust
#+CAPTION: 由于设置了 min-width: 0; 使得 flex item 最小尺寸是 0，flex-shrink 可以收缩到容器内，避免溢出。
[[file:./images/flex-box-with-overflow/layout-min-width.webp]]

或者给 flex item 设置一个具体的 =width= 。

不过此时由于 flex item 默认 =flex-grow: 0=, 不会延展尺寸，因此还要设置 =flex-grow: 1=, 让 flex item 去延展填满剩余空间。

#+attr_html: :class dark-adjust
#+CAPTION: 由于设置了 width: 0;
#+CAPTION: 此时 flex item 宽度取 width，即为 0，可以看到 basic 的位置在 0 的位置，也就不会溢出。
#+CAPTION: 但是为了要显示内容，还需要设置 flex-grow: 1, 让 flex item 能够撑开到容器宽度。
[[file:./images/flex-box-with-overflow/layout-width.webp]]

如果都不设置，那么 flex item 此时的最小尺寸由 /content size suggestion/ 决定：

#+begin_quote
The content size suggestion is the [[https://www.w3.org/TR/css-sizing-3/#min-content][min-content size]] in the main axis,
clamped, if it has an aspect ratio, by any definite min and max cross
size properties converted through the aspect ratio, and then further
clamped by the max main size property if that is definite.

[[https://www.w3.org/TR/2018/CR-css-flexbox-1-20181119/#min-size-auto:~:text=The%20content%20size%20suggestion%20is%20the%20min%2Dcontent%20size%20in%20the%20main%20axis%2C%20clamped%2C%20if%20it%20has%20an%20aspect%20ratio%2C%20by%20any%20definite%20min%20and%20max%20cross%20size%20properties%20converted%20through%20the%20aspect%20ratio%2C%20and%20then%20further%20clamped%20by%20the%20max%20main%20size%20property%20if%20that%20is%20definite][Source]]
#+end_quote

min-content size 最终会由 [[https://www.w3.org/TR/CSS2/visudet.html#float-width][CSS2.1§10.3.5]] 确定最小尺寸的计算，具体来说是：

#+begin_quote
Calculation of the shrink-to-fit width is similar to calculating the
width of a table cell using the automatic table layout algorithm.

Roughly: calculate the preferred width by formatting the content
without breaking lines other than where explicit line breaks occur,
and also calculate the preferred minimum width,

e.g., by trying all possible line breaks. CSS 2.1 does not define the exact algorithm.

Thirdly, find the available width: in this case, this is the width of
the containing block minus the used values of 'margin-left',
'border-left-width', 'padding-left', 'padding-right',
'border-right-width', 'margin-right', and the widths of any relevant
scroll bars.

[[https://www.w3.org/TR/CSS2/visudet.html#float-width:~:text=to%2Dfit%22%20width.-,Calculation%20of%20the%20shrink%2Dto%2Dfit%20width%20is%20similar%20to%20calculating,width%20is%3A%20min(max(preferred%20minimum%20width%2C%20available%20width)%2C%20preferred%20width).,-10.3.6%20Floating%2C%20replaced][Source]]
#+end_quote

#+begin_quote
Then the shrink-to-fit width is: ~min(max(preferred minimum width, available width), preferred width)~.
#+end_quote

- preferred width :: 元素不换行的宽度，本例子就是文本的长度
- preferred minimum width :: 对元素尝试各种换行，得到的最小宽度（但由于设置了 =white-space: nowrap;= , 所以应该是和 preferred width 一样的）
- available width :: 盒子宽度，400px

根据公式，最小宽度就是 ~min(max(2000+px, 400px), 2000+px) => 2000+px~

所以默认最小宽度很长，导致了溢出。

#+attr_html: :class dark-adjust
#+CAPTION: 最小宽度即文本宽度，可以看到 min 和 basic 的位置都溢出了容器。
[[file:./images/flex-box-with-overflow/layout-default.webp]]

* 推论
:PROPERTIES:
:CUSTOM_ID: 5e281bfa-547d-4548-8fa2-ab7c564a09aa
:END:

使用 flex 布局的时候，可以给 flex item 设置 =min-width: 0= ，从而保证 flex item 能够尽可能地收缩，避免溢出 flex container。

当碰到 flex item 的尺寸和预想中不一样时，可以考虑是不是这个原因导致的。
