#+begin_quote
- *遵守合同规定的工作时间。*

- *避免主动超越。*
  许多公司鼓励通过有影响力的工作来获得晋升，但与其追逐内部晋升，不如专注于转换公司，实现职业生涯的下一步。

由此，我们可以识别出一些常见的概念：

- 任务（Task） :: 一个任务。实际逻辑由任务描述符定义，例如 Makefile 和 Excel 公式。
- 输入（Input） :: 任务的输入。
- 输出（Output） :: 任务的输出。任务的输出可能是下一个任务的输入。
- 信息（Info） :: 构建信息，即跨构建的信息，可用于下一次构建。
  例如，在 Make 中，文件的修改时间就是其信息，可以理解为打包工具中的缓存。

- 构建（Build） :: 构建。基于上述概念，我们可以将构建理解为：根据定义的任务和现有的存储，输入新的输入以生成新的存储。

1. 任务是否重新执行。

这两点分别对应两个相对重要的概念：重建器（Rebuilder）和调度器（Scheduler）。
