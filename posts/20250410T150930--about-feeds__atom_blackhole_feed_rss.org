* 什么是订阅源 (feed / RSS)？
:PROPERTIES:
:CUSTOM_ID: 00fdbf68-1aba-4387-a568-759538cc84a3
:END:

订阅源 (feed) 是一种规范，其中以 [[https://zh.wikipedia.org/zh-tw/RSS][RSS(Really Simple Syndication)]] 最广为人知，此外还有 [[https://zh.wikipedia.org/wiki/Atom_(%E6%A8%99%E6%BA%96)][Atom]] 规范。[fn:1]

按照这个规范，人们可以发布订阅源，然后感兴趣的读者可以订阅他们发布的订阅源。

你可以想象成订杂志/报纸，在你订阅之后，每当有更新，你就会收到新的内容，想看什么你就订阅什么，你也可以自己发布让别人订阅。

或者类比成视频网站的关注，当你关注了一个 UP 主，他更新了你就会收到通知，同样的，你也可以成为 UP 主，发布你的内容。

大部分网站都有订阅源，其中大多数是博客和新闻网站，当你看到一个这样的按钮：

#+begin_export html
<img src="/images/about-feeds/orange-square.svg">
#+end_export

就意味着网站上存在 RSS 订阅源，你可以点击按钮找到订阅源链接进行订阅。

当你只订阅一个网站时，你可能会觉得没有节省多少时间。

但是当你最终订阅 10 个或 20 个网站时，你会发现你的订阅应用程序将成为你获取新闻和了解最新信息的常用场所。

你不需要经常从书签里找到那些你喜欢看的网站，你只要打开订阅应用程序，你订阅的都内容在那里等着你。

你不会错过任何内容，没有算法会决定从你的订阅源中删除内容。

想要停止接收？只需取消订阅该订阅源即可。

* 如何获取订阅应用程序？
:PROPERTIES:
:CUSTOM_ID: 93303b34-73c9-4a22-9480-8770d95e1b13
:END:

要订阅，你需要有一个订阅应用程序去记录订阅源，解析订阅源的内容。

它感觉有点像电子邮件应用程序，因为它有一个包含所有最新内容的收件箱。

有许多不同的订阅应用程序可供选择。

在你的手机或笔记本电脑上安装一个应用程序，或者通过网站使用订阅应用程序。

以下是一些订阅应用程序：

- [[https://follow.is][Folo]]

  得益于 [[https://docs.rsshub.app/][RSSHub]]，除了能订阅文章，它还能订阅视频，图片等，可玩性比较高。

  几乎支持全平台，web, iOS, android, windows, linux, macOS 都能用。

  我推荐用 web，随时随地都能用。

- [[https://github.com/FreshRSS/FreshRSS][FreshRSS]] - 一个可以自己部署的服务，简单够用。只支持 web。
- [[https://feedly.com][Feedly]] - 免费提供最多 100 个订阅。支持 web, android, iOS。
- [[https://www.inoreader.com][Inoreader]] - 免费提供最多 150 个订阅。支持 web, android, iOS。
- [[https://github.com/skeeto/elfeed][elfeed]] & [[https://github.com/remyhonig/elfeed-org][elfeed-org]] - 如过你是一个 Emacs 用户，你可以使用 elfeed，简单够用。

选择哪个并不重要，因为这些应用都可以很容易地导出你的订阅列表，并在将来将它们移动到另一个应用程序。

选择一个你喜欢的就好了，如果你实在不知道怎么选，就用 [[https://follow.is][Folo]] 吧。

* 如何使用订阅应用程序订阅订阅源？
:PROPERTIES:
:CUSTOM_ID: 0306d02e-9a85-4ff8-8f5d-909e50119e65
:END:

你需要找到订阅源 URL。

要获得此 URL，打开你要订阅的网站并找到该 RSS 链接或订阅源图标。[fn:2][fn:3]

然后...

- 如果你在用电脑，右键单击链接并选择 “复制链接地址” 或类似选项。
- 如果你在用手机等移动设备，点击并按住链接直到出现菜单，选择 “复制链接” 或类似选项。
- 或者你可以点击订阅链接后，复制浏览器的 URL。

然后转到你的订阅应用程序，并寻找一个功能，其名称类似于：

- “订阅”（"Subscribe"）
- “添加网络订阅源” ("Add Web Feed")
- 或者可能是一个 “+” 图标

并粘贴订阅源 URL。

这就好啦！｡:.ﾟヽ(*´∀`)ﾉﾟ.:｡

你现在可以在你的订阅应用程序中阅读最新内容。

* 谁制作了这个网站？
:PROPERTIES:
:CUSTOM_ID: fb75dbfe-6ec3-40a0-9d77-6b3a9ba92b16
:END:

[[https://aboutfeeds.com][About Feeds]] 是 [[https://interconnected.org][Matt Webb]] 制作的一个免费网站。

作者创建这个网站是因为他觉得第一次使用网络订阅源很难，他想解决这个问题。[fn:4]

而我看到后觉得很棒，然后翻译了一下加入到自己的博客，也稍微添加了一些适合中文读者的修改。

你是网站所有者吗？

请考虑在你的订阅源链接或 RSS 图标旁边添加一个 [[https://aboutfeeds.com][帮助！什么是订阅源？]] 的链接。[fn:5]

如果你有权访问代码，可以考虑 [[https://github.com/genmon/aboutfeeds/blob/main/tools/pretty-feed-v3.xsl][pretty-feed.xsl]][fn:6] 设置你的订阅源样式，使其对新用户友好。

要贡献或提供反馈，请 [[https://github.com/genmon/aboutfeeds/issues/8][在 GitHub 上的 About Feeds 存储库上发起讨论]]。[fn:7]
