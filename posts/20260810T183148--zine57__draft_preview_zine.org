- [[https://welshtroll.co.uk/post/2026-resized-for-readers-comfort.html][Resized For Readers Comfort]] by Kris

  適當將字體調大可以讓文章閱讀起來更輕鬆舒服，
  字體大一些不用費勁去看清，如果你是博客作者我推薦你試試。

  你可以用 [[https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/clamp][clamp()]] 動態基於屏幕寬度調整字體大小： ~clamp(22px, calc(22px + 0.6vw), 24px)~ ；
  也可以設置固定大小，用 [[https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media][媒體查詢]] 分別設置電脑上和手機上的大小。

- [[https://blog.neil-lin.com/blog/life-notes/2026/07/coffee-knowledge/][咖啡小知識]] by Neil Lin

  咖啡的主要成份是水，所以水是很重要的，
  如果是做手冲咖啡，礦泉水比純水要好，裡面的鈣和鎂可以讓咖啡更好喝。
  具體來說，鈣可以引出質感，即咖啡的本味和口感（果汁感、茶感）；而鎂可以引出酸味（水果味）。
  不過普通人沒那麼多心思去研究水，一般建議是用農夫山泉。

- [[https://frantic.im/mirage/][The Productivity Mirage]] by Alex Kotliarskyi

  作者喜歡折騰編輯器，以提高自己的效率，在 Hackathons 上他遇見了大佬 Bob，
  他想學學 Bob 的什麼編輯技巧，發現大佬只是用 Sublime 和朴實無華的 printf，而且還贏得了 Hackathons。

  #+begin_quote
  我過於關注他 /如何/ 做事，完全忽略了他 /在做什麼/ 。
  他的產品品味與直覺比他使用的編輯器設定更重要。

  每當我在 X 上瀏覽時，總會想到這個故事。
  每天，都有人發明新的工作方式，聲稱能改變 一切。或許真的會有。

- [[https://en.andros.dev/blog/e0e00b4b/eww-the-emacs-browser-you-underestimate/][EWW, the Emacs browser you underestimate]] by Andros Fenollosa

  EWW 是 Emacs 內置的瀏覧器，完全用 Emacs Lisp 編寫，將 HTML 轉換成 Emacs 的中的文本格式。

  EWW 不支持 JS 和 CSS，如果你的網站用 EWW 打開能正常瀏覧，
  說明你的網站 HTML 寫得比較標準，文章也分享了如何編寫 HTML 使其能在 EWW 中表現更好。

  #+begin_quote
  此流程：

  1. 有個想法。
  2. 開始寫一篇短文。
  3. 它不起作用。擴展成完整的部落格文章。
  4. 仍然不好。刪除草稿，將文字複製到筆記中。
