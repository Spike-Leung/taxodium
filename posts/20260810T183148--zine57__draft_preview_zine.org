- [[https://blog.neil-lin.com/blog/life-notes/2026/07/coffee-knowledge/][咖啡小知識]] by Neil Lin

  咖啡的主要成份是水，所以水是很重要的，
  如果是做手冲咖啡，礦泉水比純水要好，裡面的鈣和鎂可以讓咖啡更好喝。
  具體來說，鈣可以引出質感，即咖啡的本味和口感（果汁感、茶感）；而鎂可以引出酸味（水果味）。
  不過普通人沒那麼多心思去研究水，一般建議是用農夫山泉。

- [[https://nickwignall.com/how-to-take-feedback-without-getting-defensive/][How to Take Feedback without Getting Defensive]] by Nick Wignall

  在收到負面回饋和批評時，難免會有些不開心，產生一些負面情緒，可能還會有一些防禦性的行為。
  情緒是難以控制的，但是否要順著情緒做出行為是可以控制的。
  會出現負面情緒，往往是因為：

  #+begin_quote
  我們在被批評或收到負面回饋後感受到的情緒痛苦，大多來自於一種微妙的心態，
  _將批評視為對我們人格、核心信念或自我價值的攻擊。_
  因而產生大量痛苦情緒是合理的：
  如果真的有人在批評你本質的存在，你自然會感到憤怒、悲傷、恐懼或羞恥。

  [[https://nickwignall.com/how-to-take-feedback-without-getting-defensive/#:~:text=Much,ashamed][Source]]
  #+end_quote

  不過作者認為，大多時候人們都不是在人身攻擊，他們只是表遠的比較笨拙，依然是出於善意的。
  此時，把批評看作是一次讓自己變得更好的機會，也許負面情緒就會少一些。

  #+begin_quote
  但大多數情況下並非如此。
  _大多數批評與回饋——即使表達方式拙劣或缺乏同理心——最終都是出於善意。_
  _無論你是否相信這一點，將其視為事實來處理，通常是面對批評與回饋最務實的方式。_
  為此，我的建議如下：

  *將批評重新框定為學習與成長的機會，而非攻擊。*

  從這個角度看，無論批評多麼負面（或意圖多麼好或壞），最終都是正面的，因為它提供了讓你變得更好、成長的機會。

  [[https://nickwignall.com/how-to-take-feedback-without-getting-defensive/#:~:text=But%20the,grow,-%2E][Source]]
  #+end_quote

  #+begin_details
  #+html: <summary>語法</summary>

  #+begin_src css
    @route --home { pathname: url-pattern('/'); }
    @route --about { pathname: url-pattern('/about'); }
    @route --detail { pathname: url-pattern('/detail/:id'); }

    /* Going from home to about? Slide left! */
    @navigation (from: --home) and (to: --about) {
      @view-transition {
        navigation: auto;
        types: slide-all-to-left;
      }
    }

    /* Going back from about to home? Slide right! */
    @navigation (from: --about) and (to: --home) {
      @view-transition {
        navigation: auto;
        types: slide-all-to-right;
      }
    }

- [[https://www.joshtumath.uk/posts/2026-07-02-lets-fix-the-webs-text-size/][Talk: Let's fix the web's text size]] by Josh Tumath

  如果你好奇為什麼系統字體調大後，瀏覧器的字體却沒有跟著變大，這篇文章可以給你解答。

  在頁面上可以用下面兩個方法解决這個問題：

  - [[https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/meta/name/text-scale][<meta name="text-scale">]]: ~<meta name="text-scale" content="scale">~ ，目前瀏覧器支持度一般。
  - [[https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/env#preferred-text-scale][preferred-text-scale]] : ~font-size: calc(16px * env(preferred-text-scale));~

  文章裡還分享了一些頁面文字縮放的注意事項。
