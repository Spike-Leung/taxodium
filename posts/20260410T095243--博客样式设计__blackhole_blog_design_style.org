之前参加了 [[denote:20260409T180753][CSS Naked Day 2026]]，发现博客不需要什么样式其实也能看，少去了一些字体和 JS，加载还更快一些。
想着或许可以趁着每年 CSS Naked Day 期间将博客样式重写一次，减少一些不必要的样式，让博客更轻量一些。
有个说法是，日本的伊势神宫会每隔 20 年重建一次，目的是为了让每一代的工匠都有修建的经验，
不至于丢失修建的能力。每年翻修一下博客样式，也能让自己更清楚需要什么。

大体的设计还是基于 [[denote:20250910T140613][我的博客设计]]，相比上个版本而言，移除了字体，暂时只用系统自带的字体，
这样博客可以少加载些资源。
另外移除了 [[denote:20241116T162652][pagefind]] 提供的搜索功能以及 [[https://github.com/goblindegook/littlefoot][littlefoot]] 的脚注增强功能，
一个考虑是最近的供应链攻击比较多，
这两个都是外部的 JS，不受我控制（虽然我可以下载下来，避免它们更新），
而且也不是必不可少的功能，还是少加载一些 JS 吧。
不过由于 Webmention 需要渲染 HTML 内容，还是保留了一个 ~purify.min.js~ 的外部 JS 依赖。
剩下的一些 JS 都是我自己编写的，都比较简短，也在我的控制下。

这次重写，使用了 [[https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@layer][@layer]] 去分类样式，也尝试用 [[denote:20241007T123052::#5d75b436-2b28-4216-9b3d-79e177927b78][文学编程]] 的形式去描述设计，尝试尝试新东西。
这个文档应该会持续迭代，样式会基于这份文档生成。

*** html / body / font
:PROPERTIES:

定义 ~<html>~ 的样式：
- 指定字体、字号、后面基于 ~<html>~ 字体大小，使用 [[https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/font-size#rems][rem]] 作为长度单位
- 设置滚动条颜色
- 设置 [[https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/scrollbar-gutter][scrollbar-gutter]] 避免滚动条造成布局偏移
- ~font-smoothing: antialiased;~ 会让字體更精細，但可能会因為太細导致有点看不清。

如果有的英文不好区分，可以考慮安装 [[https://www.brailleinstitute.org/freefont/][Atkinson Hyperlegible]] 字體。

#+begin_src css
  html {
    font-family: 'Atkinson Hyperlegible', sans-serif, system-ui;
    font-size: 20px;
    -webkit-text-size-adjust: 100%;
    scrollbar-color: var(--color-taxodium-purple) var(--color-border);
    scrollbar-color: light-dark(var(--color-taxodium-purple), var(--dark-color-taxodium-purple)) var(--color-border);
    scrollbar-gutter: stable;
    -webkit-font-smoothing: antialiased;
    font-smoothing: antialiased;
  }

  @media screen and (width >= 70em) {
    html {
      font-size: 24px;
    }
  }
#+end_src

在手机上， ~<body>~ 占据整个屏幕 (100vw)，只留些许的 padding 和屏幕边缘保留一些距离，
因为手机屏幕本来就小，还要留一些边距 (margin) 的话，留给内容的空间就更少了。

在大屏上 (width >= 55rem)，限制最大宽度，避免一行内容太长，需要频繁左右来回看。
设置左右边距 (margin-inline) 为 auto，使得 ~<body>~ 居中，而不是靠左，这样就不用侧着头看；
居中也不会让一侧留白太多。

除此之外，设置页面整体的字体颜色；1.5 的行高，避免行之间过于拥挤；
设置 ~word-wrap~ 使得较长的连续文字能够换行，不至于产生横向滚动条。

另外在还设置了一个背景图片，使得背景不那么单调乏味。
我使用的背景图是半透明的，会自动基于明暗模式适配。
如果不是半透明的图片，需要在明暗模式设置不同的图片。

    color: var(--color-text);

#+end_src

#+begin_quote
排版比例使用的比例（大多）借鉴自音乐音程。
这些比例创造了「和谐」的比例感，因为它们基于同样的数学关系，而正是这些关系让优秀的音乐听起来悦耳。

常用比例：

- 小三度 (1.200) - 细微
- 大三度 (1.250) - 均衡
- 纯四度 (1.333) - 略显张力
- 纯五度 (1.500) - 醒目
- 黄金比例 (1.618) - 非音程，但常用

这些比例是指数级的，而非线性的。每个标题级别都是在前一个级别的基础上乘以比例，而不是相加。

以下是使用大三度比例 (1.25) 时，各标题级别的指数级增长情况：

#+begin_src text
h6: 1rem × 1.25⁰ = 1rem
h5: 1rem × 1.25¹ = 1.25rem
h4: 1rem × 1.25² = 1.563rem
h3: 1rem × 1.25³ = 1.953rem
h2: 1rem × 1.25⁴ = 2.441rem
h1: 1rem × 1.25⁵ = 3.052rem
#+end_src

其模式为：基础大小 × 比例 ^ 指数。

这就是 [[https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/pow][pow()]] 发挥作用的地方。

[[https://www.alwaystwisted.com/articles/building-typographic-scales-with-headings-sibling-index-and-pow][Building Typographic Scales in CSS with :heading(), sibling-index(), and pow()]]
#+end_quote
#+end_details

因为标题本身字体就很大，行高太大，就会有很多多余的空白，所以将行高降低为 1.2。

目前 Firefox 還不支持 ~animation-timeline~ 。

注意添加 ~@media (prefers-reduced-motion: reduce)~ 基于用戶配置关閉動画。

- ~animation-timeline: view();~ 让元素基于 viewport 控制動画
- ~animation-range-start~ 和 ~animation-range-end~ 控制動画执行区間，見 [[https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/timeline-range-name#exit][<timeline-range-name> CSS type]]
- ~animation-fill-mode: both;~ 让動画結束后保持状态

動画謹慎用 ~filter~ ，可能会在手機上造成严重的性能問題。
