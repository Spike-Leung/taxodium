- [[https://www.joshwcomeau.com/animation/css-vs-javascript/][CSS vs. JavaScript]] by Josh W. Comeau

  文章比较了用 CSS 和 JS 實現動畫兩者的性能差异。

  由於 JS 動晝运行在浏览器的主綫程上，当主綫程被中斷時，動畫就會被暂停；
  而 CSS 獨立於主綫程运行，不會被中斷。

  結論是能用 CSS 就用 CSS，不能用時考慮用一些動畫庫，如 [[https://motion.dev/][Motion]]、[[https://gsap.com/][GSAP]]，
  這些庫會处理 JS 卡頓問題，將卡頓的影响降低。

- [[https://www.react.doctor/blog/the-problem-with-useeffect][The problem with useEffect]]

  文章描述了一些使用 ~useEffect~ 常碰到的問題，
  并推薦用結合 ESLint 和 [[https://github.com/millionco/react-doctor][millionco/react-doctor]] 提前發現問題。
