最近用 [[https://help.kagi.com/kagi/translate/][Kagi Translate]] 蛮多的，我觉得使用体验还不错，在这里分享一下。

#+attr_html: :role note
#+begin_section
虽然 Kagi Translate 可以免费使用，但如果要解锁所有功能，需要订阅 [[https://help.kagi.com/kagi/plans/plan-types.html#:~:text=unlimited%20access%20to%20Universal%20Summarizer%20and%20Kagi%20Translate%2C][Professional Plan]] ($10/month)。
#+end_section

[[https://translate.kagi.com][Kagi Translate]] 是一个集成了 LLM 的翻译服务，它提供了好几个功能：

- Text，输入文字翻译
- Proofread，校对文本
- Dictionary，词典
- Document，翻译文档（TXT、PDF、JSON 等多个格式）
- Website，翻译网站

在 Text 页面你可以直接打开输入内容翻译：

#+CAPTION: Kagi Translate Text 界面
[[file:images/my-experience-with-kagi-translate/text.webp]]

你会看到，Kagi Translate 还提供了几种替代的翻译供你参考。

如果只是输入一个单词，会有详细的单词解释，也可以跳转到 Kagi Assistant 进一步对话了解。

#+CAPTION:
[[file:images/my-experience-with-kagi-translate/text-to-emoji.webp]]

你可以切换 standard / best 模式，best 理论上翻译质量会更好，但耗时会更久。

#+CAPTION:
[[file:images/my-experience-with-kagi-translate/text-style.webp]]

你还可以进一步调整翻译风格，例如用文言风格、用更口语化的词语、
针对读者的性别优化语言、提供进一步的背景信息优化翻译。

#+CAPTION:
[[file:images/my-experience-with-kagi-translate/text-option.webp]]

除了常见的语言，它甚至还可以翻译成克林贡语、精灵语，
或者用 Z 世代、Linkin、Reddit 的语言习惯翻译（图一乐）。

#+CAPTION:
[[file:images/my-experience-with-kagi-translate/text-to-klingon.webp]]

在 Proofread 可以输入文字，它会帮你检查语法错误，以及给出一些建议。

#+CAPTION:
[[file:images/my-experience-with-kagi-translate/proofread.webp]]

Dictionary 主要就是翻译单词，但给出的信息很详细，包括了解释、同义词、例句、词源。
我比较喜欢的一个功能是它可以将信息导出到 Anki（需要安装 Anki，具体流程见 ...），
这样就可以累积不认识的单词，有空的时候在 Anki 上复习。

#+CAPTION:
[[file:images/my-experience-with-kagi-translate/dictionary.webp]]

#+CAPTION:

Document 可以翻译文档，也可以上传文档进行 Proofread，解析完成后，还支持转换成其他格式。
排版还可以，但速度一般。

#+CAPTION:

Website 可以输入一个网址，翻译成对应的语言阅读。
除了在页面上调用，还可以通过 URL、书签调用。

#+CAPTION:
[[file:images/my-experience-with-kagi-translate/website.webp]]

#+CAPTION:
[[file:images/my-experience-with-kagi-translate/website-demo.webp]]

为了方便使用，可以安装 Kagi Translate 的浏览器插件，插件提供了 Text、Dictionary 和 Website 的功能，
可以通过快捷键快速调用。

#+CAPTION:
[[file:images/my-experience-with-kagi-translate/extension.webp]]

如果你的系统是 iOS，还可以下载 Kagi Translate 的应用，可以将 iOS 默认的翻译替换成 Kagi Translate
（默认的翻译功能不好用，总是需要下载语言包）。

应用还可以识别语言，用于翻译人与人之间的对话，和其他语言的人沟通应该挺好用。
我发现的一个使用场景是识别视频的文字内容，有时看动画，
有的台词我很喜欢，但没有对应的日文，就可以用它来识别。

唯一的缺点是它没法和 Anki 联动。

我之前一直在用 [[https://immersivetranslate.com/en/][Immersive Translate]] 阅读英文网页，确实帮助很大，得益于 LLM 有大量的数据训练，
LLM 的翻译质量很不错，较少出现意义不明的翻译
（不过 LLM 更多是直译，而如果说人类翻译上存在优势，那就是恰到好处的意译吧）。
翻译虽然好用，但依赖翻译不利于增进英语阅读能力，有的设计有趣的网页，翻译过后可能会影响布局，
如果想更好的阅读英文内容，还是得增进自身的阅读能力，而不是过分依赖外部工具。
Immersive Translate 如果不是按年订阅的话，一个月的价格是 69 元，
而 Kagi Professional Plan 一个月的价格是 10 美元，相差得不多，
但 Kagi 可以用来搜索、使用 LLM 对话、翻译功能也基本满足使用，
所以我后续大概不会再续费 Immersive Translate 了，尽量依靠自身能力阅读，
实在不行就通过 Kagi Translate 翻译，然后用 Anki 积累单词，慢慢积累词汇量。
