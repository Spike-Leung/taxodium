最近在写离职交接文档，打算把一些项目的 README.md 更新一下，便于后续的人了解项目。

Emacs 中可以集成 [[https://github.com/jrblevin/markdown-mode][markdown-mode]] 扩展编辑 markdown 的能力，
它默认用 [[https://www.gnu.org/software/emacs/manual/html_mono/eww.html][EWW]] 进行预览，但 EWW 的样式相对比较简单。
我希望预览的 markdown 样式和实际在 GitHub/GitLab 上看到是差不多的，这样可以提前发现一些排版问题。

最早的时候，我参考 [[https://wikemacs.org/wiki/Markdown#Live_preview_as_you_type][Live preview as you type]]，使用 [[https://github.com/skeeto/impatient-mode][Impatient Mode]] 和 [[https://github.com/Naereen/Strapdown.js/][StrapDown.js]] 渲染。
它的原理是开启一个 HTTP 服务，将 Emacs 中的 [[https://www.gnu.org/software/emacs/manual/html_node/emacs/Buffers.html][buffer]] 渲染成 HTML 进行预览，
每当 buffer 的内容变化，就主动发送新的 HTML 内容进行更新。
HTML 中加载 [[https://github.com/markedjs/marked][Marked]]，将 markdown 内容转换 HTML 标签展示。

尽管 StrapDown.js 提供了不少 [[https://bootswatch.com/][主题]]，但都和 GitHub 上的样式有差异。
主题其实就是加载 CSS，
所以，通过替换对应的 CSS 文件，就可以实现 GitHub 的 markdown 样式，例如使用 [[https://github.com/sindresorhus/github-markdown-css][github-markdown-css]]。
最终，我就得到这样一个 markdown 的实时预览方法:

#+begin_details
#+html: <summary>相關代碼</summary>
#+begin_src emacs-lisp
  (use-package impatient-mode
    :commands (spike-leung/preview-markdown spike-leung/disable-preview-markdown)
    :config
    (defun spike-leung/imp-markdown-filter (buffer)
      "Define imp markdown filter.
  Wrap BUFFER with HTML, render with https://github.com/markedjs/marked,
  sanitize with https://github.com/cure53/DOMPurify and style with
  https://github.com/sindresorhus/github-markdown-css."
      (princ (with-current-buffer buffer
               (format "<!DOCTYPE html>
  <html>
    <head>
      <meta charset=\"utf-8\">
      <title>Markdown Preview</title>
      <link rel=\"stylesheet\" href=\"https://cdnjs.cloudflare.com/ajax/libs/github-markdown-css/5.9.0/github-markdown.min.css\" integrity=\"sha512-Ouq1+UcR9ENXndFyd/YA9i+ETLJmX3WoaMBF/nDzdqJbipKGL/SAbkO+qjDoxfD/dhZs4ZqgR9vXkolrK77xmQ==\" crossorigin=\"anonymous\" referrerpolicy=\"no-referrer\">
      <style>
            .markdown-body {
                    box-sizing: border-box;
                    min-width: 200px;
                    max-width: 980px;
                    margin: 0 auto;
                    padding: 45px;
            }

            @media (max-width: 767px) {
                    .markdown-body {
                            padding: 15px;
                    }
            }
      </style>
      <script src=\"https://cdn.jsdelivr.net/npm/marked/lib/marked.umd.js\"></script>
      <script src=\"https://cdnjs.cloudflare.com/ajax/libs/dompurify/3.4.17/purify.min.js\" integrity=\"sha512-2wT0W6vojz3cJuLoa/DxrPVQRinkfRjFWMWIDK4NghTqObEhpem1nEkeK0d9ZE+/hyvfMNuJZlfxM4LsRgeoSA==\" crossorigin=\"anonymous\" referrerpolicy=\"no-referrer\"></script>
    </head>
    <body>
      <div id=\"markdown-body\" class=\"markdown-body\"></div>
      <script>
        // The markdown source is base64 encoded on the Emacs side, so it can
        // contain any character (quotes, backslashes, newlines, raw HTML tags,
        // ...) without breaking this script block.
        const bytes = Uint8Array.from(atob(\"%s\"), c => c.charCodeAt(0));
        const markdown = new TextDecoder('utf-8').decode(bytes);
        const body = document.getElementById('markdown-body');
        if (!window.marked || !window.DOMPurify) {
          body.textContent = 'Markdown preview assets failed to load (offline or SRI mismatch).';
        } else {
          body.innerHTML = DOMPurify.sanitize(marked.parse(markdown));
        }
      </script>
    </body>
  </html>"
                       (base64-encode-string
                        (encode-coding-string
                         (save-restriction
                           (widen)
                           (buffer-substring-no-properties (point-min) (point-max)))
                         'utf-8)
                        t)))
             (current-buffer)))

    (defun spike-leung/preview-markdown ()
      "Live Preview markdown."
      (interactive)
      ;; Enabling `impatient-mode' resets the user filter, so install the
      ;; filter afterwards.
      (impatient-mode 1)
      (imp-set-user-filter #'spike-leung/imp-markdown-filter)
      (imp-visit-buffer))

    (defun spike-leung/disable-preview-markdown ()
      "Disable preview markdown."
      (interactive)
      (when (bound-and-true-p impatient-mode)
        (impatient-mode -1))
      (imp-remove-user-filter)
      ;; `httpd-stop' shuts down the server for every buffer, so only stop it
      ;; when no other buffer is being previewed.
      (unless (seq-some (lambda (buf)
                          (with-current-buffer buf
                            (bound-and-true-p impatient-mode)))
                        (buffer-list))
        (ignore-errors (httpd-stop)))))
#+end_src

最新代碼見 [[https://github.com/Spike-Leung/Spikemacs/blob/main/lisp/init-prog.el][init-prog.el]] 中 markdown 部分。
#+end_details

使用時，打開一個包含 markdown 內容的 buffer，执行 ~spike-leung/preview-markdown~ 即可。
