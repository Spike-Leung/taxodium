如果你做过前端开发，那么对 [[https://docs.npmjs.com/cli/v11/configuring-npm/package-json][pacakge.json]] 一定不陌生，它描述了：

- 项目名称、版本等基本信息
- 项目依赖的外部工具/库
- 运行项目所需的命令脚本

而其中，依赖项都会有对应的版本号，例如: ="vue": "^2.6.14"=, ="vue-template-compiler": "~2.6.14"= 。

但你会不会总是搞不明白版本号前面的标记 =^= 和 =~= 的作用？

例如上面的两个依赖，它们可使用的版本号范围是多少呢？

#+begin_details
#+HTML: <summary>答案</summary/>

=^2.6.14= := ~>=2.6.14 <3.0.0-0~

=~2.6.14= := ~>=2.6.14 <2.(6+1).0-0~ := ~>=2.6.14 <2.7.0-0~
#+end_details

如果你答对了，我想你肯定有你的记忆方法，欢迎留言分享。

如果你也容易忘记，那么接下来我想分享一个我的记忆方法，或许对你有帮助。

* 关于版本号

package.json 的版本号遵循[[https://semver.org/lang/zh-CN/][语义化版本 2.0.0]]：

#+begin_quote
版本格式： =主版本号.次版本号.修订号= ，版本号递增规则如下：

- 主版本号 (MAJOR) :: 当你做了不兼容的 API 修改，
- 次版本号 (MINOR) :: 当你做了向下兼容的功能性新增，
- 修订号 (PATCH) :: 当你做了向下兼容的问题修正。

先行版本号 (pre-release) 及版本编译信息 (build metadata) 可以加到 “ =主版本号.次版本号.修订号= ”的后面，作为延伸。
#+end_quote

packcage.json 中[[https://docs.npmjs.com/cli/v11/configuring-npm/package-json#git-urls-as-dependencies][关于版本号范围的定义]]是这样的:

#+begin_details
#+HTML: <summary>版本号范围定义</summary/>
- version :: 必须完全匹配 ~version~
- >version :: 必须大于 ~version~
- >=version :: 大于等于 ~version~
- <version :: 必须小于 ~version~
- <=version :: 小于等于 ~version~
- *~version* :: 大致相当于 =version= (参见 [[https://github.com/npm/node-semver#versions][semver]])
- *^version* :: 与 ~version~ 兼容 (参见 [[https://github.com/npm/node-semver#versions][semver]])
- 1.2.x :: ~1.2.0~, ~1.2.1~, 等等，但不包括 ~1.3.0~
- * :: 匹配任何版本
- "" :: (空字符串) 等同于 ~*~
- version1 - version2 :: 等同于 ~>=version1 <=version2~
- range1 || range2 :: 如果 ~range1~ 或 ~range2~ 满足，则通过。
- http://... :: 参见 [[https://docs.npmjs.com/cli/v11/configuring-npm/package-json#urls-as-dependencies][URLs as Dependencies]]
- git... :: 参见 [[https://docs.npmjs.com/cli/v11/configuring-npm/package-json#git-urls-as-dependencies][Git URLs as Dependencies]]
- user/repo :: 参见 [[https://docs.npmjs.com/cli/v11/configuring-npm/package-json#github-urls][GitHub URLs]]
- tag :: 一个特定的版本，被标记并发布为 ~tag~ (参见 [[https://docs.npmjs.com/cli/v11/commands/npm-dist-tag][npm dist-tag]])
- path/path/path :: 参见[[https://docs.npmjs.com/cli/v11/using-npm/package-spec#aliases][本地路径]]
- npm:@scope/pkg@version :: 包的自定义别名 (参见 [[https://docs.npmjs.com/cli/v11/using-npm/package-spec#aliases][package-spec]])
#+end_details

除了 =^= 和 =~= 其实都是比较容易明白的。

* ^ (Caret Ranges) 和 ~ (Tilde Ranges)

=主版本号.次版本号.修订号=

[[https://github.com/npm/node-semver?tab=readme-ov-file#caret-ranges-123-025-004][^ (Caret Ranges)]] :: 允许不修改 =[major, minor, patch]= 元组中最左边非零元素的更改。换句话说，这允许对 =1.0.0= 及以上版本进行补丁和次要更新，对 =0.X >=0.1.0= 版本进行补丁更新，对 =0.0.X= 版本不进行更新。

- [[https://github.com/npm/node-semver?tab=readme-ov-file#caret-ranges-123-025-004][~ (Tilde Ranges)]] :: 如果存在 =次版本号= ，则允许进行 =修订号= 修改。如果没有，则允许 =次版本号= 的更改。
