逛 [[https://emacs-china.org/][Emacs China]] 的时候看到了一下在 Emacs 中翻译的插件，我也配置了一些，最近也在使用 [[https://platform.deepseek.com/][deepseek]]，它的 API 是和 [[https://platform.openai.com/docs/overview][OpenAI]] 兼容的，于是我就配置了一下，翻译的效果还不错。

我想记录一下我都使用了什么插件，怎么配置的以及是如何使用的。

* 插件使用

插件我主要使用这几个：

- [[https://github.com/Elilif/emacs-immersive-translate][Elilif/emacs-immersive-translate]] ::  Immersive-translate provides bilingual simultaneous display and translation of any text in Emacs.
- [[https://github.com/lorniu/go-translate][lorniu/go-translate]] :: : Translator on Emacs. Supports multiple engines such as Google, Bing, deepL, ChatGPT, StarDict, Youdao and so on.
- [[https://github.com/condy0919/fanyi.el][condy0919/fanyi.el]] ::  Not only English-Chinese translator for Emacs.
- [[https://github.com/karthink/gptel][karthink/gptel]] :: A simple LLM client for Emacs

我使用最多的是 emacs-immersive-translate，它的灵感是 [[https://immersivetranslate.com/en/][Immersive Translate]]，是我使用频率极高的一个浏览器翻译插件。

emacs-immersive-translate 给我的体验和 Immersive Translate 很接近，我主要是用来查看 Emacs 中的 Info，它还有 immersive-translate-auto-mode，可以在 buffer 变化的时候自动翻译，挺方便的。

最开始时我没有 OpenAI 的 APIKey，我用的是 [[https://github.com/soimort/translate-shell][translate-shell]]，实际上就是 [[https://translate.google.com/][Goolge Translate]]。

Google Translate 速度很快，缺点是有的时候翻译不是那么准确，但也基本够用了。

emacs-immersive-translate 针对 Emacs 中的 Info，[[https://github.com/skeeto/elfeed][elfeed]] 等做了适配，总体效果看起来是不错的，每次我看 Info 都会用到。

而 go-translate 的灵活度会更高一些，我主要用来选中文本之后进行翻译。

fanyi 则是当作字典使用，碰到一两个单词不熟悉，则使用 fanyi 进行查询。

我很喜欢 fanyi 里面的 [[https://dict.cn/][海词]]，它可以生成图表，呈现单词含义的使用频率，让我了解这个单词最常见的含义。

最后，我还会用到 gptel，它实际上不是专门用来翻译的，但是作为 LLM，我可以在任何地方调用它，帮我完成一些翻译任务。

* 插件配置

你可以在 [[https://github.com/Spike-Leung/emacs.d/blob/main/lisp/my-lisp/init-translate.el][init-translate.el]] 中查看翻译的相关配置。

** emacs-immersive-translate

你可以在 [[https://melpa.org/][MELPA]] 上直接安装 emacs-immersive-translate。

不过我修改了源码，[[https://github.com/Spike-Leung/emacs-immersive-translate/commit/330dcfa3603845ead9408000577b429f8c47ee87][调整了翻译文字颜色]]，所以我是作为 [[https://git-scm.com/docs/gitsubmodules][git submodules]] 安装的。

然后我配置了使用 [[https://platform.deepseek.com/][deepseek]] 作为翻译服务：

#+begin_src elisp
  (push (expand-file-name "lisp/my-lisp/emacs-immersive-translate" user-emacs-directory) load-path)
  (require 'immersive-translate)
  ;; need to add deepseek api-key with user `apikey` in `.authinfo`
  (setq immersive-translate-backend 'chatgpt
        immersive-translate-chatgpt-host "api.deepseek.com"
        immersive-translate-chatgpt-model "deepseek-chat"
        immersive-translate-pending-message "(≖ᴗ≖๑)"
        immersive-translate-failed-message "(つд⊂) ")
#+end_src

然后需要在 ~~./authinfo~  中配置 apikey，由于 emacs-immersive-translate 是查找 user 为 =apikey= 的配置，因此 user 这里需要设置为 =apikey=
#+begin_src authinfo
  machine api.deepseek.com login apikey password ********************************
#+end_src

** go-translate

go-translate 也是可以在 [[https://melpa.org/][MELPA]] 上直接安装。

我将它配置成使用 [[https://platform.deepseek.com/][deepseek]] 作为翻译服务，翻译显示在一个新的 [[https://www.gnu.org/software/emacs/manual/html_node/emacs/Buffers.html][buffer]] 中。

#+begin_src elisp
  ;; @see: https://github.com/lorniu/go-translate
  (maybe-require-package 'go-translate)
  (maybe-require-package 'plz)
  (with-eval-after-load 'go-translate
    (setq gt-langs '(en zh)
          gt-chatgpt-key (spike-leung/get-deepseek-api-key)
          gt-chatgpt-host "https://api.deepseek.com"
          gt-chatgpt-model "deepseek-chat"
          gt-default-translator (gt-translator
                                 :engines (list
                                           (gt-chatgpt-engine))
                                 :render (gt-buffer-render
                                          :buffer-name "gt-translator"
                                          :window-config '((display-buffer-at-bottom))
                                          :then (lambda (_) (pop-to-buffer "gt-translator"))))))

#+end_src

apikey 也是配置在 ~~/.authinfo~ 文件，使用 ~spike-leung/get-deepseek-api-key~ 这个方法从文件中查找对应的密钥。
