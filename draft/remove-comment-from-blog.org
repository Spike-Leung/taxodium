如果你留意的话，会发现博客文章中的 [[https://giscus.app/][giscus]] 留言消失了，这不是 bug，而是我故意移除的。

为什么要移除呢？

1. 留言的人并不是很多，这个功能看起来用处不大，而且需要额外加载一个第三方的脚本，偶尔在切换明暗主题的时候也存在一些主题错乱的问题
2. giscus 是依赖 GitHub 账号的，有的读者或许想留言，但还要登录 GitHub，或许就放弃了
3. giscus 没有审查，虽然我也能删除留言，但总归不会那么及时。我不太确定会有什么内容，会不会有人利用来投广告，或者发布一些恶意言论？对此我有点担心
4. 除了 giscus，也有一些留言系统，是可以审核的，也支持输入邮箱直接留言
