** 关于博客

如你所见，博客的名字是 [[https://www.wikiwand.com/en/articles/Taxodium][Taxodium]]，是一种树，叫落羽杉。

落羽杉的叶子像一根下垂的羽毛，高中校园里种了不少，周记中还写过它。也许是因为这个缘故，在我想要一个博客名称的时候，很自然地想到了它。也有一种遗落的羽毛的意味，博客就像是在收集这些偶尔遗落的思绪一般。

博客的域名是 =taxodium.ink= ，taoxidum 是博客的名称，ink 则是墨水的含义，感觉蛮适合用作博客的。

* 3. 你是如何完成创作的？

我的博客分成了 draft, post, publish 三个目录，我会现在 draft 中创建一个 org 文件，大致写一个大概，然后就开始填充内容了。

如果需要斟酌遣词用句，可能会很久都写不出来什么，所以我更倾向于先写下来一些什么，想到什么就先写下来，然后慢慢去调整文字和内容。

对于 Weekly，则是先找一个文件记录这周看过的内容，然后找一块时间去消化这些文章，归类在不同的部分。

draft 中写得差不多，就挪到 post 中，通过 org-publish 执行发布，生成 html 到 publish 目录，这个时候就是看看文章的样式，语句是否通顺，是否有错别字等。

目前的博客需要执行 org-publish 才能转换成 html 看效果，所以可能会重复几次，直到发布的文章整体看起来没什么问题。

对于图片，则是直接在 publish/images 下创建一个和文章同名的目录，将图片丢在里面引用，发布之前会尝试去压缩一下图片的大小。

当一切就绪，我就会 push 到 GitHub，自动部署到 netlify 上。

* 4. 运营博客的过程中是否有失去过动力？如果有，是为什么恢复的？如果没有，请问您又是如何保持创作的激情？

从最开始创建博客，后面过了四五年，其实都没写什么文章，一个月能写一篇都很了不起了。

没有动力，主要是不知道写些什么，当时的想法是既然要写，就要写一些相对来说还有点用的经验，但这样反而会给自己带来压力，然后就拖延了起来。

2021 年的时候从第一家公司离职回家，当时也是疫情也比较严重，在家 Gap 了好一段时间。

这个期间准备一些面试问题，空闲时间比较多，就又开始记录一些内容，但还是偏技术方向的。

等找到工作了，没有什么空闲时间了，又开始松懈了。

2022 年给自己定了一个目标，至少每个月写一篇博客，倒是勉勉强强完成了。

到了 2023 年，虽然也有这个目标，也找到一些技术问题想去研究，但是还是因为懒，搁置了。

也许是想写的东西没有那么强烈的兴趣吧，强迫自己去写，就比较抗拒。

2023 年开始订阅了一些 newsletter 和周刊，看到一些蛮有趣的，就想分享出来，当时在公司写了一个简单的爬虫，爬取一些信息，自己每周定期整理一些信息，整合成 Markdown 通过钉钉的 webhooks 发送到群里。

后来又把每周的 Markdown 用 Deno 写了个查看的页面，便于大家看历史的内容。

但是没啥反响，时间久了有点失去动力了。

但是收集信息，整理到笔记系统的习惯倒是保留了下来。

后来也看到很多人写周刊，就想，为什么我不写一份呢？把平时自己看到的一些内容整理出来，或许也有人看呢？

于是就开始写周刊，至今也写了 13 周啦。

周刊成了我的一个信息站，可以把一些自己认为比较有趣的信息记录起来，需要的时候也可以翻出来。

期间也把博客收录到了 v2ex 的 [[https://www.v2ex.com/xna][VXNA]] 中，在 VXNA 发现了很多有趣的博客，通过这些有趣的博客，又发现了更多有趣的博客。

让我觉得有趣的，不是博客里的技术干货文章，反倒是作者的许多兴趣，感悟，生活。

后来也想开了，其实我也可以去记录一些生活小事，自己的牢骚。

让写博客这件事情轻松一点，不用要求一定要写成什么样，想写就写。

* 5. 如何搭建博客，以及运营博客每年需要投入的资金？

投入资金只有域名费用，一年 60 元。

关于我博客的搭建，可以看[[https://taxodium.ink/org-publish-blog][使用 org-publish 发布博客]]

（果然每个博客里面都会有一篇记录怎么折腾博客的文章ˊ・ω・ˋ）

博客的搭建我希望尽可能的简单，自己对于博客要能够完全掌控，想怎么改就怎么改，尽可能不要依赖过多服务。

我希望博客也尽可能的简洁，没有太多的杂乱的元素，你可以在网络比较差的情况也比较快的加载它。
