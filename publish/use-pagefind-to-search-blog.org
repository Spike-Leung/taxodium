这周用 [[https://pagefind.app/][pagefind]] 给博客添加一个 [[https://taxodium.ink/search][搜索页面]]，如果你感兴趣可以搜索看看。

一直都想给博客添加一个搜索功能，加上最近开始写周刊，
里面整理了不少的链接，有时候我想找点东西，能够搜索的话就会方便很多。

以前尝试过 [[https://www.algolia.com/][algolia]] ，但配置起来有点麻烦，也显得很重，效果并不满意。

这周看到了一个开源项目 [[https://pagefind.app/][pagefind]]，它可以对构建好的 HTML 进行索引和搜索，
配置简单，开箱即用，没有额外的第三方服务，很符合我的需要。

* 关于 pagefind
:PROPERTIES:
:CUSTOM_ID: 8146bd66-566b-49de-9e2b-796bc84fa98f
:END:

#+begin_quote
Pagefind 是一个完全 *静态* 的搜索库，其目标是在大型网站上运行良好，
同时 *尽可能少地占用用户带宽* ，并且无需托管任何基础设施。

[[https://pagefind.app/][pagefind]]
#+end_quote

pagefind 的一些特点：

- 零配置支持多语言网站
- 使用 NodeJS 索引库索引任何内容（例如 PDF、JSON 文件或字幕）
- 以相同的低带宽占用提供所有功能

对我来说，它最大的优点就是配置简单，不依赖第三方服务，而且搜索效果也不错。

* 配置 pagefind
:PROPERTIES:
:CUSTOM_ID: d0cb0641-caef-4bb1-8bd5-f55349aa923c
:END:

配置 pagefind 很简单，你只需要两步：

1. 执行 =npx -y pagefind --site publish= 生成索引，其中 =publish= 是你的静态页面存放的目录
2. 引用对应的 CSS，JS，并且添加一个 DOM 元素让 pagefind 挂载

#+begin_src html -r
  <link href="/pagefind/pagefind-ui.css" rel="stylesheet">
  <script src="/pagefind/pagefind-ui.js"></script>
  <div id="search"></div>
  <script>
    window.addEventListener('DOMContentLoaded', (event) => {
      new PagefindUI({ element: "#search", showSubResults: true });
    });
  </script>
#+end_src

这样你就拥有搜索功能了 ヾ(*´∀ ˋ*)ﾉ

下面分享一下我是如何集成的。

** CI/CD 中添加索引指令
:PROPERTIES:
:CUSTOM_ID: 8a7bf407-8909-44d5-ad65-75a4d48ba47a
:END:

我的博客[fn:1]是部署在 [[https://www.netlify.com/][Netlify]]，我只需要在构建的最后，添加 [[(pagefind-command)][一行执行索引的指令]] 就完成索引了。

#+begin_src bash -r
  #!/bin/bash

  # Enable command printing (debug mode)
  set -x

  # Only build when `publish` change
  git diff --quiet $CACHED_COMMIT_REF $COMMIT_REF publish

  # index.xml is for https://www.v2ex.com/xna
  cp -f publish/rss.xml publish/index.xml

  npx -y pagefind --site publish --force-language zh-CN (ref:pagefind-command)

  # Disable debug mode
  set +x
#+end_src

如果你仔细看的话，会发现我的指令添加了 =--force-language zh-CN= 的 option，
这会告诉 pagefind 要将不同语言的页面都生成到同一个索引里。

[[https://pagefind.app/docs/multilingual/#:~:text=When%20indexing%2C%20Pagefind%20will%20look%20for%20a%20lang%20attribute%20on%20your%20html%20element.%20Indexing%20will%20then%20run%20independently%20for%20each%20detected%20language.%20When%20Pagefind%20initializes%20in%20the%20browser%20it%20will%20check%20the%20same%20lang%20attribute%20and%20load%20the%20appropriate%20index.][pagefind 的默认逻辑是按照语言各自建立索引]]，当你的页面的 [[https://developer.mozilla.org/en-US/docs/Web/HTML/Global_attributes/lang][lang]] 是 en 的时候，
它只会检索 en 页面对应的索引，而不会检索 zh-CN 页面的索引。

但是我希望在一个统一的地方，能够搜索到我博客所有的内容，因此我需要它将不同语言的页面索引放到一起。

** 引用 pagefind 资源
:PROPERTIES:
:CUSTOM_ID: 23066128-897c-40cf-8243-04d8238d55cc
:END:

相比于在文章页面上添加搜索，我更倾向于一个独立的搜索页面，避免搜索结果影响文章页面的布局。
单独一个页面，在我不需要的时候也可以轻易移除。

#+NAME: search.html
#+begin_src html -r
  <!DOCTYPE html>
  <html lang="zh-CN"> (ref:zh-cn)
    <head>
      <!-- ... -->
      <link href="/pagefind/pagefind-ui.css" rel="stylesheet">
      <script src="/pagefind/pagefind-ui.js"></script>
    </head>
    <body>
      <div id="search"></div>
      <script>
        window.addEventListener('DOMContentLoaded', (event) => {
          new PagefindUI({
            element: "#search",
            showSubResults: true,
            showImages: false, (ref:showImages)
            autofocus: true,
            excerptLength: 50, (ref:excerptLength)
          });
        });
      </script>
    </body>
  </html>
#+end_src

页面上我设置了 [[(zh-cn)][lang="zh-CN"]] ，pagefind 会基于 lang 去匹配索引和组件的多语言文字。
之前我的页面都是 ~lang="en"~ ，pagefind 将页面按照 en 索引，导致我搜索不到任何内容。
因此我也更新了博客页面的 [[https://developer.mozilla.org/en-US/docs/Web/HTML/Global_attributes/lang][lang]] 属性，从 en 改为了 zh-CN，这样 [[https://www.youtube.com/watch?v=NP94u7y_KkQ][对于使用屏幕阅读器的人也会友好一点]]。

[[(showImages)][showImages]] 我设置成了 false，因为我的博客文章基本没有封面图，图片还会增加搜索时的带宽消耗。

[[(excerptLength)][excerptLength]] 可以考虑设置一个大一点值，这样关键字附近的上下文会多一些。

页面完整代码你可以查看 [[file:search.html][搜索页面]] 的源码。

** 调整 excerpt 的样式
:PROPERTIES:
:CUSTOM_ID: 0DE52050-E2B9-4DD9-91FE-E7369C07D394

参考 [[https://www.zolkos.com/2025/12/03/vanilla-css-is-all-you-need][Vanilla CSS is all you need]]，可以给 ~<mark>~ 添加一个样式，看起来像是用记号笔圈起来一样。

#+attr_html: :class dark-adjust
#+CAPTION: excerpt 的样式
[[file:images/use-pagefind-to-search-blog/pagefind-mark-style.webp]]

首先，新增一个 ~<span>~ 用于承载样式，
可以通过 [[(processResult)][processResult]] 将 excerpt 返回的 ~<mark>~ [[(replace)][替换成]] ~<mark><span></span>~ 。
虽然只用一个 ~<mark>~ 也可以实现类似样式，但 ~border~ 连接的地方混色会有问题。

#+begin_src javascript -r
  new PagefindUI({
    element: "#search",
    showSubResults: true,
    showImages: false,
    autofocus: true,
    excerptLength: 50,
    processResult: function (result) { (ref:processResult)
      result.excerpt = result.excerpt.replaceAll("<mark>", "<mark><span></span>") (ref:replace)
      result?.sub_results.forEach((sr) => {
        sr.excerpt = sr.excerpt.replaceAll("<mark>", "<mark><span></span>")
      })
      return result;
    }
  });
#+end_src

* 一些建议
:PROPERTIES:
:CUSTOM_ID: C5CBE53A-0D3E-475A-B2FC-607367583477
:END:

由于 pagefind 依赖 JS，但是用户可能禁用了 JS，或者某些原因导致 pagefind 的 JS 加载错误，
此时搜索就失效了。针对这种场景，考虑添加一段文本，引导用户使用搜索引擎搜索：

#+begin_quote
如果你未启用 JavaScript，也可以使用你喜欢的搜索引擎进行搜索。例如：[[https://kagi.com/search?q=site%3Ataxodium.ink][Kagi]]、[[https://www.google.com/search?q=site%3Ataxodium.ink][Google]]。
#+end_quote
