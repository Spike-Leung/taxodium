    「有人說」在媒體中是個簡寫，表示這是一種意見、直覺或直覺感受，卻沒有人願意署名。它借用了「有一定數量的人」在背後支持的暗示，試圖僅僅透過暗示有多人持相同觀點來獲得可信度。這些人往往不存在，他們只是用來提出觀點或支持議程的工具。這種語言的使用迎合了我們的思維模式：當事物附帶一個數字時，就具有重量、能施加力量並且有存在感，但這只是一個技巧。

  • How to Take Feedback without Getting Defensive by Nick Wignall

    在收到負面回饋和批評時，難免會有些不開心，產生一些負面情緒，可能還會有一些防禦性的行為。情緒是難以控制的，但是否要順著情緒做出行為是可以控制的。會出現負面情緒，往往是因為：

    我們在被批評或收到負面回饋後感受到的情緒痛苦，大多來自於一種微妙的心態，將批評視為對我們人格、核心信念或自我價值的攻擊。因而產生大量痛苦情緒是合理的：如果真的有人在批評你本質的存在，你自然會感到憤怒、悲傷、恐懼或羞恥。

    Source

    不過作者認為，大多時候人們都不是在人身攻擊，他們只是表遠的比較笨拙，依然是出於善意的。此時，把批評看作是一次讓自己變得更好的機會，也許負面情緒就會少一些。

    但大多數情況下並非如此。大多數批評與回饋——即使表達方式拙劣或缺乏同理心——最終都是出於善意。無論你是否相信這一點，將其視為事實來處理，通常是面對批評與回饋最務實的方式。為此，我的建議如下：

    將批評重新框定為學習與成長的機會，而非攻擊。

    從這個角度看，無論批評多麼負面（或意圖多麼好或壞），最終都是正面的，因為它提供了讓你變得更好、成長的機會。

    一份 CSS 草案，可以基於頁面路由變化設置不同 CSS。

    語法 
    @route --home { pathname: url-pattern('/'); }
@route --about { pathname: url-pattern('/about'); }
@route --detail { pathname: url-pattern('/detail/:id'); }

/* Going from home to about? Slide left! */
@navigation (from: --home) and (to: --about) {
  @view-transition {
    navigation: auto;
    types: slide-all-to-left;
  }
}

/* Going back from about to home? Slide right! */
@navigation (from: --about) and (to: --home) {
  @view-transition {
    navigation: auto;
    types: slide-all-to-right;
  }
}

  • There are no lossless transformations of natural-language text by Sophie Alpert

    你必須為文件中的每個想法與每個句子負責。在分享文件之前，確認整份文件都能代表你自己的想法，是你的責任。如果審閱者問：「你這一行是什麼意思？」你不能回答：「喔，抱歉，那是 AI 寫的，忽略它就好。」如果你呈現給讀者的內容並不能真實代表你的想法，就會讓讀者感到困惑（也浪費他們的時間）。有些情況下，讀者會察覺並指出不一致之處；但在其他情況下，他們會誤以為那就是你真正的想法。

    Source

    撰寫文件所花的時間應該多於閱讀文件所花的時間。如果你只用一個簡短的提示生成文件，接著要求讀者閱讀較長的輸出內容，那就是不尊重他們的時間。他們如果想用 ChatGPT，隨時都可以自己使用。大多數文件由一個人撰寫，卻會被許多人閱讀，因此讀者為了理解你的意思而需要額外花費的任何時間，都會對團隊的時間造成倍數增加的成本。反過來說，如果你在傳送文件前多花一些時間，讓內容清楚、簡潔，你只需支付一次性的成本，而每位讀者都能從中受益。

    Source

    越長並不代表越好。Pascal 曾寫道：「我把這封［信］寫得比平常長，是因為我沒有時間把它縮短。」 AI 讓生成長篇文件變得容易許多，而它採用的策略之一，就是加入許多幾乎沒有傳達任何重要內容、反而削弱實際內容的句子。如果你是根據較短的提示產出較長的文字，不妨考慮直接分享提示本身。如果你使用 AI 進行編輯，但不讓內容變長，空洞句子的風險會降低一些，但你的意思仍可能因此變得晦澀難懂。

    自然語言文本不存在無損轉換——每一次改寫與換句話說，都會改變你文字的含義；如果這件事是由一個並不具備你個人試圖傳達之內容最詳盡心智表徵的實體完成，資訊就會遺失。即使得犧牲所謂的「潤飾」，讀者也會樂於聽見你的想法。

    Source

  • Simultaneous Monologues by Tim Klapdor

    媒體所做的，是劫持人類互動的概念，並加以顛覆。它不創造對話，而是打造一個同時進行獨白的場所 —— 每個聲音都是自己的明星 —— 然後把音量調高。

    Source

    網路確實有能力進行對話，但無法大規模實現。對話是以人為尺度的——不是機器，不是網路，而是直接且緊密相連的互動。而且，對話並不只是用來宣洩歧見的空間。對話往往需要某種基本程度的共同理解，才能運作：界線、規則與慣例——或許未明說，但彼此都心照不宣。這種相互性只有在人與人之間的尺度上才可能發生。

    儘管人們一直在談論城鎮廣場，我們仍必須記住，廣場並不是辯論或對話的場所，而是讓我們站在各自的講台上彼此叫喊的空間。對話的家園在舒適的酒吧與咖啡館裡、沙發與休憩室中、漫長的散步途中，或圍坐在火爐旁——在共同的場所裡。也許我們從來不需要線上的城鎮廣場。我們需要的，是更接近那些舒適空間的事物。
