如果你留意的话，会发现博客文章中的 giscus 留言消失了，不是不小心，是故意的。

当初为什么要添加留言？

  1. 我希望能收到反馈，希望知道有人喜欢我的内容，或者给我一些建议，哪怕点个赞也好。

    人还是渴望被看见的吧

    推论是，如果你发现了那篇帖子，就说点什么。

    给作者发个消息，留个评论。

    没有其他人这样做。

    互联网上有成千上万的人在发布优质内容，却不知道是否有人看到或欣赏。

    Source

  2. 我确实也收到了一些反馈，指出了我内容中的问题，纠正了我对某个知识点的认识。有时评论区的讨论也可以延伸内容。
  3. 不少博客都有，我也想有。
  4. 博客的框架内置了，开启了试试。

为什么要移除呢？

  1. 留言的人并不是很多。

  2. 需要额外加载一个第三方的脚本。

    偶尔在切换明暗主题的时候也存在 一些主题错乱的问题，少一个功能我就可以少维护一些东西。

  3. giscus 是依赖 GitHub 账号的，有的读者或许想留言，但还要登录 GitHub，就放弃了。

  4. giscus 没有审查。

    虽然我能删除留言，但总归不会那么及时。

    我不太确定会有什么内容，会不会有人利用来投广告，或者发布一些恶意言论？

    或者单纯就是不喜欢我的内容，拉踩我一下？

    我不喜欢负面的内容一直挂着，但随便删除读者留言也不太友好，让人纠结，纠结就会内耗，就会不开心，我不想不开心。

  5. 除了 giscus，也有一些留言系统，是可以审核的，支持输入邮箱直接留言而不需要注册账号，但往往也需要依赖一些第三方服务，嫌麻烦。

    还有 Webmention

    在 我想让自己说话不那么“端着” 中我还了解到了另外一种可以用于留言的技术 ⸺ Webmention。但它需要不少的处理，也是嫌麻烦，懒得维护。而且读者可能觉得登录 GitHub 都麻烦，更别说发一个 webmention 了。目前我已经集成了，见 给博客添加 Webmention。

  6. 回复留言有时让我感到有压力。

    有人说喜欢我要表达一下感谢；有人给出建议，我要考虑要不要调整；有人推荐了一些东西，我要去尝试一下才能回复；

    有时我什么不想回，但不回又觉得似乎冷落了对方；回复也需要斟酌语言……

  7. 我会经常翻 GitHub，看看有没有回复，大多数时候我都有点失落，因为什么回复都没有。

    我也不想因为评论而频繁刷 GitHub，就像 Zine#36 中提到的关于 Folo 的使用 ，我总会过一段时间就看看，感觉有点病态。

    太在乎有没有人看、有多少人看以及别人的意见。

  8. 如果读者真的想和我交流，可以通过邮件，这样更直接，更私密，也可以更深入。

    有的留言系统还需要考虑如何通知读者，而邮件本身就带有这样的功能，不需要额外维护什么服务。

    缺点是，关于文章的交流不是公开的，但如果讨论内容有价值，其实可以手动整理到文章中。

  9. 没有了留言，或许会有点孤独感，不知道有没有人在看，有没有人关注。

    但说到底写博客还是为自己而写的，有人看固然很好，没人看也无所谓，自己开心就好。

    既然是为自己而写，那也不用太在乎读者会怎么看，不用太在乎写得好不好，想怎么写就怎么写，或许表达上会更自由。

    我也希望我的博客成为我的 安全空间，我不用担心什么，我自在，读者也自在。
