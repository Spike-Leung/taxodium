博客禁用 JavaScript 也是可以正常閱讀的，但允許加載 JS 的話，会多一些增強的功能。
如果禁用 JS 后影响閱讀请告訴我，我会想办法調整的, thanks :)

*博客內置*

- [[file:js/backtop.js][backtop.js]] 用于返回頂剖
- [[file:js/code-enhanced.js][code-enhanced.js]] 代碼复制、代碼隨鼠標滾動
- [[file:js/code-highlighted.js][code-highlighted.js]] 代碼行高亮
- [[file:js/color-scheme.js][color-scheme.js]] 明暗主題切換
- +[[file:js/copy-feed-url.js][copy-feed-url.js]] 复制訂閱流 URL+
- [[file:js/heading-enhanced.js][heading-enhanced.js]] 点击 heading 后定位 heading
- [[file:js/sidenote.js][sidenote.js]] 將脚注显示为旁注
- +[[file:js/snow-fall.js][snow-fall.js]] 冬天下雪特效+
- +[[file:js/toc.js][toc.js]] 固定目录󠄃、高亮当前目录󠄃位置+
- [[file:js/translate.js][translate.js]] 点击頂部 Kagi translate 按钮跳转 Kagi translate 翻譯
- [[file:js/webmention.js][webmention.js]] 底部 webmention 所需，从 [[https://webmention.io/][webmention.io]] 拉取数据后渲染 HTML
  + [[file:js/purify.min.js][purify.min.js]] (見下方 DOMPurify)

*第三方*

- [[https://github.com/cure53/DOMPurify][DOMPurify]] 用于渲染 HTML 時进行 [[https://developer.mozilla.org/en-US/docs/Web/Security/Attacks/XSS][XSS]] 清洗
- [[https://www.mathjax.org/][MathJax]] 用于部分頁面渲染数学公式
