1 什么是订阅源 (feed / RSS)？
=============================

  订阅源 (feed) 是一种规范，其中以 [RSS(Really Simple Syndication)]
  (<https://zh.wikipedia.org/zh-tw/RSS>) 最广为人知，此外还有 [Atom]
  (<https://zh.wikipedia.org/wiki/Atom_(%E6%A8%99%E6%BA%96)>) 规范。

  按照这个规范，人们可以发布订阅源，然后感兴趣的读者可以订阅他们发布的订阅源。

  elfeed 的作者写了篇文章 [Atom vs. RSS] (<https://nullprogram.com/blog/2013/09/23/>)，
  如果你要创建一个订阅源，建议使用 Atom，因为它更严格，能够避免一些错误。

  你可以想象成订杂志/报纸，在你订阅之后，每当有更新，你就会收到新的内容，想看什么你就订
  阅什么，你也可以自己发布让别人订阅。

  或者类比成视频网站的关注，当你关注了一个 UP 主，他更新了你就会收到通知，同样的，你也可
  以成为 UP 主，发布你的内容。

  大部分网站都有订阅源，其中大多数是博客和新闻网站，当你看到一个这样的按钮：

  就意味着网站上存在 RSS 订阅源，你可以点击按钮找到订阅源链接进行订阅。

  当你只订阅一个网站时，你可能会觉得没有节省多少时间。但是当你最终订阅 10 个或 20 个网站
  时，你会发现你的订阅应用程序将成为你获取新闻和了解最新信息的常用场所。

  你不需要经常从书签里找到那些你喜欢看的网站，你只要打开订阅应用程序，你订阅的都内容在那
  里等着你。你不会错过任何内容，没有算法会决定从你的订阅源中删除内容。

  想要停止接收？只需取消订阅该订阅源即可。


2 如何获取订阅应用程序？
========================

  要订阅，你需要有一个订阅应用程序去记录订阅源，解析订阅源的内容。它感觉有点像电子邮件应
  用程序，因为它有一个包含所有最新内容的收件箱。

  有许多不同的订阅应用程序可供选择。在你的手机或笔记本电脑上安装一个应用程序，或者通过网
  站使用订阅应用程序。

  以下是一些订阅应用程序：

  - [Folo] (<https://follow.is>)

    得益于 [RSSHub] (<https://docs.rsshub.app/>)，除了能订阅文章，它还能订阅视频，图片等，
    可玩性比较高。几乎支持全平台，web, iOS, android, windows, linux, macOS 都能用。我推
    荐用 web，随时随地都能用。(但是现在手机上使用会被重定向到应用下载了)

  - [FreshRSS] (<https://github.com/FreshRSS/FreshRSS>) - 一个可以自己部署的服务，简单够
    用。只支持 web。
  - [Feedly] (<https://feedly.com>) - 免费提供最多 100 个订阅。支持 web, android, iOS。
  - [Inoreader] (<https://www.inoreader.com>) - 免费提供最多 150 个订阅。支持 web,
    android, iOS。
  - [Glance] (<https://github.com/glanceapp/glance>) - 一个自己部署的服务，界面还不错。
  - [NetNewsWire] (<https://github.com/Ranchero-Software/NetNewsWire>) - 免费的应用，只
    支持 macOS 和 iOS。
  - [elfeed] (<https://github.com/skeeto/elfeed>) & [elfeed-org]
    (<https://github.com/remyhonig/elfeed-org>) - 如过你是一个 Emacs 用户，你可以使用
    elfeed，简单够用。

  选择哪个并不重要，因为这些应用都可以很容易地导出你的订阅列表，并在将来将它们移动到另一
  个应用程序。


3 如何使用订阅应用程序订阅订阅源？
==================================

  你需要找到订阅源 URL。

  要获得此 URL，打开你要订阅的网站并找到该 RSS 链接或订阅源图标。

  例如当前页面的导航上的 「订阅」 就是订阅链接，你可以右键点击复制链接；或者点击进去后，
  复制浏览器的 URL。

  有的网站不提供订阅流，需要你输入邮箱订阅，你可以使用 [kill-the-newsletter]
  (<https://github.com/leafac/kill-the-newsletter>) 进行转换。kill-the-newsletter 会给你
  生成一个订阅的邮箱，然后为你生成订阅流。

  然后...

  - 如果你在用电脑，右键单击链接并选择 “复制链接地址” 或类似选项。
  - 如果你在用手机等移动设备，点击并按住链接直到出现菜单，选择 “复制链接” 或类似选项。
  - 或者你可以点击订阅链接后，复制浏览器的 URL。

  然后转到你的订阅应用程序，并寻找一个功能，其名称类似于：

  - “订阅”（"Subscribe"）
  - “添加网络订阅源” ("Add Web Feed")
  - 或者可能是一个 “+” 图标

  并粘贴订阅源 URL。

  这就好啦！｡:.ﾟヽ(*´∀`)ﾉﾟ.:｡

  你现在可以在你的订阅应用程序中阅读最新内容。


4 接下来做什么？
================

  寻找更多阅读内容！

  + [Blogroll] (<https://blogroll.org>) 和 [ooh.directory] (<https://ooh.directory>) 这
    两个都是手工整理的博客目录，按主题组织。
  + [中文独立博客列表] (<https://github.com/timqian/chinese-independent-blogs>)
  + [中文博客琅琊榜] (<https://github.com/qianguyihao/blog-list>) - 个人整理的博客列表
  + [优秀个人独立博客导航] (<http://www.jetli.com.cn/>) - 个人整理的博客列表
  + [VXNA] (<https://www.v2ex.com/xna>) - [v2ex] (<https://www.v2ex.com/xna>) 论坛发起的
    一个订阅源聚合页面，不少博客作者在上面发布了订阅源。
  + [BlogFinder] (<https://bf.zzxworld.com/>)
  + [awesome-newsletters] (<https://github.com/zudochkin/awesome-newsletters>)
  + [Bear Discovery feed] (<https://bearblog.dev/discover/>)
  + [powRSS] (<https://powrss.com/index.html>)
  + [url.town] (<https://url.town/>)
  + [XXIIVV webring] (<https://webring.xxiivv.com/>)
  + 当你有喜欢的博客作者，你也可以去看看博客作者关注的人，去发现更多有趣的内容。
  + 还有更多……

  开始你自己的博客！
  + [Get Blogging!] (<https://getblogging.org>) 是一个关于开始博客的实用指南。
  + [HTML is for people] (<https://htmlforpeople.com/>) 教你用 HTML 搭建你自己的页面，没
    有很复杂的内容，容易入门。
  + TODO: 找一个中文教程或者自己写一个
  + 还有更多……

  不要局限于中文内容！

  你可以用 [沉浸式翻译] (<https://immersivetranslate.com/zh-Hans/>) 帮助你在浏览器和手机
  上阅读，你的视野可以更宽广！


5 谁制作了这个网站？
====================

  [About Feeds] (<https://aboutfeeds.com>) 是 [Matt Webb] (<https://interconnected.org>)
  制作的一个免费网站。作者创建这个网站是因为他觉得第一次使用网络订阅源很难，他想解决这个
  问题 ([了解作者为什么要做这个网站] (<https://aboutfeeds.com/why>))。而我看到后觉得很棒，
  然后翻译了一下加入到自己的博客，也稍微添加了一些适合中文读者的修改。

  你是网站所有者吗？

  请考虑在你的订阅源链接或 RSS 图标旁边添加一个 [帮助！什么是订阅源？]
  (<https://aboutfeeds.com>) 的链接。(或者你也可以指向 [我写的这篇文章]
  (<file:about-feeds.org>))

  如果你有权访问代码，可以考虑 [pretty-feed.xsl]
  (<https://github.com/genmon/aboutfeeds/blob/main/tools/pretty-feed-v3.xsl>) 设置你的订
  阅源样式，使其对新用户友好。

  作者使用的是 RSS，如果你是用 Atom，你可以参考我的 [pretty-feed-v3.xsl]
  (<https://github.com/Spike-Leung/taxodium/blob/org-publish/publish/styles/pretty-feed-v3.xsl>)
  ，或者看看这个 [issue] (<https://github.com/genmon/aboutfeeds/issues/26>)。你也可以考
  虑用 [RSS.Beauty] (<https://github.com/ccbikai/RSS.Beauty>)。

  要贡献或提供反馈，请 [在 GitHub 上的 About Feeds 存储库上发起讨论]
  (<https://github.com/genmon/aboutfeeds/issues/8>)。如果有能力，也可以给这个仓库做贡献，
  使其支持 Atom 和多语言。
