博客加載的 JavaScript

博客禁用 JavaScript 也可以正常閱讀，但允許加載 JS 的話，会多一些增強的功能。如果禁用 JS 后影响閱讀请告訴我，我会想办法調整, thanks :)

博客內置

  • backtop.js 用于返回頂部
  • code-enhanced.js 代碼复制、代碼隨鼠標滾動
  • code-highlighted.js 代碼行高亮
  • color-scheme.js 明暗主題切換
  • copy-feed-url.js 复制訂閱流 URL
  • heading-enhanced.js 点击 heading 后定位 heading
  • sidenote.js 將脚注显示为旁注
  • snow-fall.js 冬天下雪特效
  • toc.js 固定目录󠄃、高亮当前目录󠄃位置
  • translate.js 点击頂部 Kagi Translate 按钮跳转 Kagi Translate 翻譯
  • webmention.js 底部 webmention 所需，从 webmention.io 拉取数据后渲染 HTML

第三方

  • purify.min.js 用于 webmention 渲染 HTML 時进行 XSS 清洗 (見 DOMPurify)
  • MathJax 用于部分頁面渲染数学公式
