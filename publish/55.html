我寫 Zine 的習慣是先在一周里收集各種連結(大部分都來自我訂閱的網站)，然後集中一個時間去处理。有的連結讀起來會比較花時間，有的我一時也不知道怎麼總結，以往我會把這樣的連結放一邊，拖到最後才处理，或者先去干點別的放鬆一下，簡而言之就是先逃避它。除非我選擇舍弃它們，否則這些連結最終都是要处理的，逃避并不會有什麼用。在 Zine#53 分享過一篇 Write Your Way Out，里面說到當需要寫作，但不想寫作時，避免寫作是無用的，反而應該繼續寫，一邊寫一邊去推進想法。後面我也是這麼實踐的，我會從頭到尾一條條連結处理過去，不管連結处理起來是否困難，這樣做下來，整體的效率更高了，不會因為一些連結而拖很久。因為决定了不管如何都要去直面，也少去了一些心理負擔，不怕困難了，反正都是要面對的。

  • Failing is Common, Trying is Rare by David

    失敗很常見，但真正的嘗試卻很罕見。

    判斷自己是否真的在努力，一個簡單的方法是問自己：「一個真正下定決心要做這件事的人會怎麼做？」當下你就會知道那個人是不是你。

    為了實現目標，應該不斷地去嘗試，直到有結果，但人們往在第一次嘗試碰壁後就放弃嘗試了，并轉向了另一個衝突的目標，例如為了不再受挫而做一些和目標無關的事，可能還在假裝努力。

    確實，很多時候面對一些要做的事我也是如此，因為怕失敗，怕受挫而選擇了逃避，明明也沒嘗試几次。嘗試了、行動了，不管好坏，至少會有一個結果，而不去嘗試，只會一無所有。

    「真正嘗試」意味著在經歷痛苦或挫折時，依然能持續鎖定目標，而不是轉向一個更次要、更懦弱的目標。

    真正的嘗試應該是一場磨練：一段漫長的經歷，由一連串精確的錯誤、痛苦和挫折組成，正是這些過程讓成功在起點之後變得可能。

    目標通常必須透過獲得起初並不具備的見解和技能來達成。你會學習如何處理各種類型的互動、專業人士究竟如何操作 X，以及如何避開陷阱 Y 和 Z。嘗試意味著忍受學習這些事物的磨練，主要是透過那些行不通的方式去實踐。如果沒有經歷磨練，要麼是你運氣好立即成功了，要麼就是你根本沒有嘗試。

    嘗試就是經歷磨練直到終點，而終點要麼是成功，要麼是真正體悟到：為了獲得獎勵所必須付出的代價，對你而言並不值得。

    判斷自己是否真的在努力，一個簡單的方法是問自己：「一個真正下定決心要做這件事的人會怎麼做？」當下你就會知道那個人是不是你。

  • How to be less awkward by Adam Mastroianni

    如何避免尷尬

    1. 放棄掩飾

      那天我學到了一個重要教訓：在尷尬這件事上，掩飾往往比犯錯本身更糟糕。如果你幾秒鐘前剛做了一件尷尬的事，你不太可能突然變得社交萬能，並保證隨後的每一招都精明有效。更有可能的是，你正在恐慌，所以你的下一個動作會比上一個更愚蠢。

      我認為，這就是減輕社交笨拙的關鍵：放棄掩飾。當你漏掉了暗示或失禮時，你只需要承擔它。必要時道歉、補救、解釋，但不要試圖用另一輪的失誤來挽回之前的錯誤。如果你撞倒了一疊瓷盤，不要試圖在別人注意到之前迅速掃起碎片；你只會接著撞倒一架子的水壺。

      Source

    2. 避免過度的自我意識

      解決過度自我意識的方法是將注意力轉向外部而非內部。你無法靠大聲叫喊來壓過內心的批評者，你必須用另一種聲音完全淹沒它。幸運的是，你身邊隨時都有其他的聲音，它們來自於其他人。你越關注別人的所作所為，留給自己揮霍的注意力就越少。

      Source

    3. 越是害怕社交，越應該去社交，會發現沒有其實想象中那麼可怕

      這意味著你可以用治療任何恐懼症的方法來治癒恐人症 ⸺ 面對它、感受它，然後忘掉它。這就是暴露與反應預防療法背後的邏輯：你坐在令你恐懼的事物面前，而不採取你慣用的應對機制（如滑手機、逃跑等），直到你對恐懼感到厭倦為止。例如，如果你患有恐蛛症，你會從安全距離凝視蜘蛛，等到心率恢復正常，再向前邁進一步，如此反覆，直到你與蜘蛛近到它願意主持你的婚禮為止。

      不幸的是，恐人症比恐蛛症更難治療，因為人不像蜘蛛，不能被放進玻璃缸並安全地安置在房間的另一頭。社交互動中不存在零風險 ⸺ 任何人隨時都可能決定不喜歡你。這就是為什麼你的恐人症不會因為持續與人類接觸而自發緩解：如果你不以一種最終能讓恐懼變得平淡的方式去面對它，你只是在助長恐懼，而非消除它。

      因此，暴露療法只有在你能做到兩件事時，才對社交恐懼症有效：累積一些愉快的互動，並在事後進行反思。累積互動聽起來可能比反思更難，但證據顯示事實恰恰相反。大多數人在大多數時候的互動大多是良好的，他們只是沒有注意到而已。

      因此，治療社交恐懼症的第一線良方，就是讓自己沉浸在日常互動的愉悅感中。如果你擔心自己的失誤會讓你注定終身孤獨，而事實上… 這並沒有發生，那麼或許值得反思這個事實，直到你的預期更新到與你的經歷相符。反覆練習，也許你的擔憂不僅會開始顯得錯誤，甚至會顯得乏味。

  • tc39/proposal-await-dictionary

    A proposal to add Promise.allKeyed to ECMAScript.

    當有多個 Promise 任務且需要等待它們都完成，現在一般的寫法是： 

    const [
  color,
  shape,
  mass,
] = await Promise.all([
  getShape(),
  getColor(),
  getMass(),
]);

    但這個語法的問題是依赖數組順序。於是有人提出了 Promise.allKeyed ，實現相同功能但不依赖順序。 

    const {
  shape,
  color,
  mass,
} = await Promise.allKeyed({
  shape: getShape(),
  color: getColor(),
  mass: getMass(),
});

游戏

巫師三

之前在 Zine#54 分享過一些感受了，前陣子我通關了，玩完了主綫劇情、石之心和血与酒兩個 DLC，現在開始了二周目。

巫師三的劇情真的很棒，兩個 DLC 也是。主綫劇情的最後，希里成為了獵魔人，之後的巫師四就是以她為主角， 2027 還會有 《巫师 3：狂猎 — 旧时曲》 DLC，大概是講述杰洛特是如何將獵魔人的身份傳承給希里吧。

石之心講述了一個人因為愛情而和惡魔做了交易，惡魔帮杰洛特脫困而要求杰洛特還債，去帮它完成那個人的三個願望，從而完成与那個人的契約，收取他的灵魂。主要的劇情就是去完成這三個願望，很喜歡和夏妮在參加婚礼的那段。

血与酒則新增了一張陶森特地圖，講述了一對王室姐妹的愛恨，妹妹因為怨恨而去欺騙了一只吸血鬼，企圖夺回一切，吸血鬼知道被騙後大開殺戒，最後解决了吸血鬼，但因為之前的劇情里沒有把一本笔記看完，最終沒法讓兩姐妹和解，妹妹還是殺了姐姐，而她也被护卫殺了，一個充滿遺憾的 Bad Ending。喜歡和妹妹在童話書的那段劇情，能看到很多熟悉的童話人物，如三只小猪、小紅帽等，蠻有创意的，二周目要好好選擇，達成 Good Ending。

二周目玩起來難度大了不少，怪的傷害高了很多，一兩下就被打死了，不過重新洗點，合理搭配角色能力就會輕松得多。二周目因為劇情都大致玩過了，沒什麼心思去推劇情，慢悠悠地做支綫，發現了很多一周目沒玩到的內容。

這類劇情向的游戏的缺點是劇情在一周目都玩過了，會讓多周目變得有些無聊，而它的解决辦法就是在劇情里加了很多支綫選擇，儘管主要劇情方向近似，但不同的選擇還會有不一樣的結局，多周目可以去體驗之前沒玩過的分支劇情，一定程度上减少重複游玩的無聊。

巫師三是 2015 年的游戏了，現在玩起來也一點不過時，甚至這麼多年後還準備出一個新的 DLC。這麼多年過去了，Bug 大多也修了，有很多攻略，價格也便宜，如果沒玩過，真的很值得入手玩玩。
